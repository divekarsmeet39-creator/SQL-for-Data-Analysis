# Task 3 – SQL-Based E-commerce Data Analysis

## Project Overview
This project is part of my Data Analyst Internship. The main goal is to explore and analyze an E-commerce database using SQL queries to extract useful information and business insights.

Using MySQL, I performed data analysis on customer details, product information, and order records to understand sales performance and database relationships.

## Tools & Technologies
- MySQL Workbench 8.0 CE
- MySQL Database
- Structured Query Language (SQL)

## Database Name
`ecommerce_analysis`

## Database Tables
The database consists of four main tables:

1. **Customers** – Contains customer IDs, names, and city information.
2. **Products** – Stores product names, categories, and prices.
3. **Orders** – Maintains order IDs, customer details, order dates, and order status.
4. **Order_Items** – Contains order-wise product details and purchase quantities.

## SQL Concepts Implemented
- SELECT and WHERE statements
- ORDER BY and GROUP BY
- INNER JOIN, LEFT JOIN, and RIGHT JOIN
- Nested Queries and Subqueries
- Aggregate Functions (COUNT, SUM, AVG)
- Creating and Using Views
- Indexing for Query Optimization
- Handling NULL Values using COALESCE

## Project Objectives
- Extract relevant information from database tables.
- Apply filtering and sorting to organize data.
- Calculate total sales, average prices, and other key metrics.
- Study customer purchasing patterns and product performance.
- Connect multiple tables using SQL joins.
- Create views to simplify data analysis.
- Use indexes to improve query execution efficiency.

## How to Execute the Project
1. Install and launch MySQL Workbench 8.0 CE.
2. Establish a connection to the MySQL server.
3. Open the project SQL script.
4. Execute the SQL commands using the lightning icon.
5. Refresh the database Schemas panel.
6. Select the `ecommerce_analysis` database.
7. Execute the queries and review the results.

## Expected Outcome
This project provides practical experience in SQL-based data analysis. It demonstrates database management, data extraction, filtering, sorting, table joins, aggregation, subqueries, views, and query optimization.

## Conclusion
By completing this task, I gained practical knowledge of MySQL and SQL operations. I also improved my understanding of how relational databases can be used to organize information, analyze E-commerce data, and generate meaningful business insights.
